================================================================
BROMO ADVENTURE TRIP 2026 — OUTFIT GUIDE
11–16 June · East Java, Indonesia
================================================================

----------------------------------------------------------------
ชุดแต่ละวัน
----------------------------------------------------------------

Jun 11 (Day 0) — Arrive Surabaya
  เดินทาง + กินข้าวเย็นแถวโรงแรม   →  ชุดลำลอง
  นอน                                →  ชุดนอน

Jun 12 (Day 1) — Madakaripura + Bromo
  Madakaripura Waterfall (เปียกโชก)  →  ชุดลุยน้ำตก
  เปลี่ยนหลัง Madakaripura เสร็จ    →  ชุดลำลอง
  นอน (ตื่น 03:00)                   →  ชุดนอน

Jun 13 (Day 2) — Bromo Sunrise
  Bromo ตี 3 (หนาว ~3°C)            →  ชุดลุยหนาว
  เปลี่ยนหลัง sunrise เสร็จ         →  ชุดลำลอง
  นอน                                →  ชุดนอน

Jun 14 (Day 3) — Waterfalls Day
  Kapas Biru + Tumpak Sewu (เปียก)   →  ชุดลุยน้ำตก
  เปลี่ยนหลัง Tumpak Sewu เสร็จ     →  ชุดลำลอง
  นอน ~4 ชม. (ตื่นตี 12)            →  ใส่ชุดลำลองนอนเลย
                                         ตื่นมาสวม cold layers ทับได้เลย

Jun 15 (Day 4) — Kawah Ijen Blue Fire
  Ijen ตี 2 (หนาว ~5°C)             →  ชุดลุยหนาว (ชุดเดิม Jun 13) ♻️
  เปลี่ยนหลัง Ijen เสร็จ ~09:30     →  ชุดเที่ยว
  นอน                                →  ชุดนอน

Jun 16 (Day 5) — Departure
  บินกลับบ้าน                        →  ชุดลำลอง


----------------------------------------------------------------
สรุปจำนวนชุดที่ต้องเตรียม
----------------------------------------------------------------

  ชุดลุยน้ำตก     2 ชุด   (Jun 12, Jun 14)
  ชุดลุยหนาว      1 set   (Jun 13 Bromo + Jun 15 Ijen ใช้ซ้ำ)
  ชุดลำลอง        3 ชุด   (Jun 11, 12, 13, 14, 16 — สลับใส่)
  ชุดเที่ยว        1 ชุด   (Jun 15 ดินเนอร์ Surabaya)
  ชุดนอน          2 ชุด   (Jun 14 ใส่ชุดลำลองนอนแทนได้)


----------------------------------------------------------------
คำอธิบายแต่ละชุด
----------------------------------------------------------------

[ชุดลุยน้ำตก]
  ใช้เมื่อ  :  Madakaripura (Jun 12) และ Waterfall day (Jun 14)
  เตรียมไว้ :  2 ชุด (เปียกทั้งคู่ ซักแล้วอาจไม่แห้งทัน)
  ประกอบด้วย
    - ชุดว่ายน้ำหรือชุดกีฬา (ใส่ข้างใน)
    - เสื้อ quick-dry ทับ
    - กางเกง quick-dry
    - เสื้อกันฝน / poncho
    - รองเท้าลุยน้ำ รัดส้น (ใส่แทน trail shoes วันนี้)
  หมายเหตุ  :  ห้ามใส่ยีนส์หรือผ้าหนา — เปียกแล้วหนักและแห้งช้า

[ชุดลุยหนาว]
  ใช้เมื่อ  :  Bromo ตี 3 (Jun 13) และ Ijen ตี 2 (Jun 15)
  เตรียมไว้ :  1 set ใช้ซ้ำได้ ซักระหว่างวัน Jun 13–15 มีเวลา
  เป็น layer system ถอดเพิ่มลดได้ตามอุณหภูมิ
    Layer 1  :  Thermal / Heattech base layer (เสื้อ + กางเกง)
    Layer 2  :  Fleece mid layer
    Layer 3  :  Down jacket มีฮู้ด (ชั้นนอกสุด)
    เพิ่มเติม :  กางเกงเดินป่าขายาว + beanie + ถุงมือ + buff
    รองเท้า  :  Trail shoes หุ้มส้น

[ชุดลำลอง]
  ใช้เมื่อ  :  นั่งรถ / กินข้าว / อยู่โรงแรม / เดินทาง
  เตรียมไว้ :  3 ชุด สลับใส่ตลอดทริป
  ประกอบด้วย
    - เสื้อยืดหรือเสื้อเบา
    - กางเกงขายาว joggers หรือ shorts
    - sneakers ทั่วไป
  หมายเหตุ  :  เน้นสบาย นั่งได้นาน รถยาว 4–5 ชม./วัน

[ชุดเที่ยว]
  ใช้เมื่อ  :  ดินเนอร์ฉลองที่ Surabaya Jun 15 เย็น
  เตรียมไว้ :  1 ชุด
  ประกอบด้วย
    - ชุดที่ดูดีกว่าชุดลำลองนิดหน่อย ไม่ต้องทางการ
    - รองเท้าที่ไม่ใช่ trail shoes
  หมายเหตุ  :  ถ้าไม่แคร์ใช้ชุดลำลองแทนได้เลย ไม่บังคับ

[ชุดนอน]
  ใช้เมื่อ  :  นอนแต่ละคืน
  เตรียมไว้ :  2 ชุด
  หมายเหตุ  :  Jun 14 นอนแค่ 3–4 ชม. แนะนำใส่ชุดลำลองนอนแทน
                ตื่นตี 12 สวม cold layers ทับได้เลย ไม่ต้องเสียเวลาเปลี่ยน


----------------------------------------------------------------
Tips การแพ็ค
----------------------------------------------------------------

  - เสื้อกันกลิ่นกำมะถัน Ijen ติดได้นาน
    → แพ็คชุด Ijen แยกถุงพลาสติกก่อนขึ้นเครื่องกลับ

  - Cold layers ซักง่าย แห้งเร็ว ถ้าซักหลัง Bromo (Jun 13)
    ทันใส่อีกรอบที่ Ijen (Jun 15)

  - ชุดลุยน้ำตก 2 ชุด เตรียมแยกไว้ในถุงซิป
    หลังเปียกเก็บลงถุงเลย ไม่ปนชุดอื่น
